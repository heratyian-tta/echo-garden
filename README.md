
                             Welcome to EchoGarden!

---------------------------------PURPOSE--------------------------------

The purpose of this application is to help users who are interested in gardening plan and create a customized garden.  The plants featured in this application are all native to the Midwest, and the initial focus will beon native gardens.  Later itterations will expand the types of plants listed in the application.

The app consists of a homepage, with a sign in or sign up button.
Upon sign in or creation of a user account, the user will be directed to their main page, which will show a graphical version of their garden, and a list of their plants. 
The application will have flash messages and notifications to remind the user to water their garden based on the watering interval for each plant.  Later itterations will include timing changes based on life stage of the plants, and the weather conditions.
The user can create a new garden, and use their x-y coordinates to create a new landscape, and launch their garden to establish a watering cycle.
In the footer of their main page, users can click on the submit feedback button, and be taken to a survey monkey site with a basic feedback function.  Later itterations, feedback can be tracked back to the user interally.
